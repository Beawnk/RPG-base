# Livros de regras

Ponha aqui o livro do sistema que você quer jogar (PDF ou texto). O mestre lê daqui pra montar o resumo em `Sistemas/` e pra tirar dúvidas de regra durante o jogo.

Esta pasta fica fora do git (direito autoral e tamanho): o `.gitignore` deixa passar só este aviso. Se você sincroniza o vault por um repositório, os livros continuam só no seu computador.
